# 展示页设计：base6-techo

## 一、产品定位与卖点

一句话主张：

> **用 LaTeX 一次生成一整本真正“装订好”的手帐 PDF——内装订/外翻边自动区分，无需手动拼版。**

拆成三个可感知的卖点：

1. **整本一次成型**：多个版式 Section 顺序拼接 → 页码连续 → 一键输出整本 PDF。
1. **装订侧自动区分**：奇数页装订在左、偶数页装订在右；内容区向装订侧让出 `binding` 边距、
   向外侧让出 `non_binding` 边距——页码、页眉、水印都随内/外侧自动镜像。
1. **三种拼版模式**：不拼版（按序输出）/ 骑马钉 booklet（整本补 4 页成帖）/ 锁线分册 thread
   （按每帖纸张数分组）。LaTeX + tectonic 负责排版，用户不用手工拼版。

展示页的职责：**让访客在 30 秒内“看见”这三个卖点**，而不是让访客读文档。

## 二、页面结构（自顶向下）

展示页采用“单页滚动 + 分层递进”，共 **7 个区块**。每个区块一个用途、一个主视觉、一句文案。

```
┌─────────────────────────────────────────────────────────┐
│ 00 顶栏 Nav                                             │
├─────────────────────────────────────────────────────────┤
│ 01 Hero（卖点首屏）                                      │
│    标题 / 副标题卖点 / 主 CTA / 背景动画（书页翻动）        │
├─────────────────────────────────────────────────────────┤
│ 02 “一次成型”整本（Section 拼装概念）                     │
├─────────────────────────────────────────────────────────┤
│ 03 “装订自动区分”图解（左右页对比）★★核心★               │
├─────────────────────────────────────────────────────────┤
│ 04 拼版三模式（不拼 / 骑马钉 / 锁线）                     │
├─────────────────────────────────────────────────────────┤
│ 05 版式画廊（16 种版式走马灯）                            │
├─────────────────────────────────────────────────────────┤
│ 06 “为什么是 LaTeX”（技术底气 / 细节）                   │
├─────────────────────────────────────────────────────────┤
│ 07 收尾 CTA + 页脚                                        │
└─────────────────────────────────────────────────────────┘
```

每个区块的“怎么介绍”细则如下。

### 00 顶栏 Nav

- 左侧产品名 **base6 techo**；右侧锚点链接：卖点、拼版、版式、技术。
- 视觉：极简、衬线标题 + 无衬线正文（呼应手帐/印刷气质）。
- 目的：让用户知道这是工具类产品页，且可快速跳到“装订区分”这一核心。

### 01 Hero（首屏）

- **大标题**（一句话卖点）：`一次排版，生成整本可内外装订的 PDF`
- **副标题**（解释“为什么”）：`基于 LaTeX + tectonic，多版式自动成书，装订边自动区分，免去手动拼版。`
- **主 CTA**：`立即使用`（下载 App）；次 CTA：`看它如何拼版 ↓`（滚动到 03）。
- **主视觉**：右侧展示一本“摊开的书”动画——左页内外边距高亮、右页镜像，暗示装订对称。
  - 若无动画素材，用一张静态 PDF 成品双页展开图亦可。
- 目的：**8 秒内把最大卖点讲清**（整本 + 内外装订 + 免拼版）。

### 02 “一次成型”整本（Section 拼装概念）

- 介绍方式：用一张“版本组装示意”图。
  - 左侧列几个版式块（横线 → 月历 → 八分周视图 → 时间轴…），标上各自页数；
  - 箭头向右汇成一个 **连续页码的整本 PDF**；
  - 标注：`16 种版式自由组合 · 页码连续 · 一个 PDF 输出`.
- 文案：`把不同版面像搭积木一样拼成一本：每个 Section 几页由参数决定，顺序即成书。`
- 目的：让用户理解“多个版式 = 一整本书”的产品形态。

### 03 “装订自动区分”图解（★★核心卖点★★）

这是全页说服力最强、必须优先做好的区块。

介绍方式：**左右两页并排的标注释图**。

- **左页（奇数页）**：装订边在左（`binding` 加粗高亮）、外侧在右（`non_binding`）；
  页眉文字居中/靠边、装订侧水印竖排贴着左侧。
- **右页（偶数页）**：装订边在右、外侧在左——**与左页完全镜像**。
- 用动画或分步高亮依次点亮：`① 装订边` → `② 外翻边` → `③ 页眉镜像` → `④ 水印镜像`。
- 文案三步讲清楚：
  1. `书本翻页：装订边在左还是右，由页码奇偶自动决定。`
  1. `内容区自动向内/外让边——内窄外宽，符合装订手感。`
  1. `页码、页眉、水印随内外侧自动镜像，无需手动调。`
- 配一个“Toggle”：装订侧宽度 / 非装订侧宽度滑块，实时看边距变化（若做交互版）。
- 目的：把“可区分内外装订”从一个抽象概念变成**视觉上一眼能懂**的图解。

### 04 拼版三模式

介绍方式：三列卡片，每张配一张“纸张摊平如何排页码”的小图。

1. **不拼版**：按页面顺序直接输出（适合电子阅读/单页打印）。
1. **骑马钉 booklet**：整本按 4 页补齐，折叠后订中间——图示 8 页 → 2 张双层纸的展开。
1. **锁线分册 thread**：按每帖 `sheets_per_group` 张纸分组拼版，适合厚本手工线装。

- 配文案：`LaTeX 负责摊牌与页码——你把选好的版式交给它，剩下交给装订机。`
- 目的：说明“免手动拼版”落实到哪三种成书方式。

### 05 版式画廊（16 种）

- 介绍方式：走马灯 / 网格缩略图，每张一个小 PDF 或缩略图 + 中文名标签。
- 分成三组展示（呼应产品内部分组）：
  - 基础：点阵、网格、横线、法文格、美式横线、古文竖排；
  - 复刻：Midori、博文館・當用日記、博文館・懐中日記；
  - 日程：月历、年度追踪、月打卡、八分周视图、时间轴、月追踪制图、年历。
- 单击可放大 / 下载样例 PDF。
- 目的：用“实物感”证明产品能产出真实可装订的纸质手帐，而不是抽象承诺。

### 06 “为什么是 LaTeX”（技术底气）

- 用 2–3 个“细节卡片”建立信任：
  - **字体/排版质量**：XeLaTeX + fontspec，任意系统字体、精确到毫米的版面控制；
  - **确定性输出**：同一参数 → 同一 PDF，可复现、可版本化；
  - **书签/大纲**：自动为每个 Section 生成 PDF 书签，成品即目录；
  - **粒度控制**：每页独立 TikZ 图，均匀点阵等自动合并优化（文件更小）。
- 目的：让技术用户/决策者认可“用 LaTeX 不是噱头，是硬需求”。

### 07 收尾 CTA + 页脚

- 重复主卖点一句 + 主 CTA `立即使用`。
- 页脚：项目简介、平台（桌面 Tauri）、仓库链接、许可证。

## 三、视觉与基调

- 气质：**印刷 / 纸感**。背景可用暖白 `#faf8f5`，主色可以用字体同款的墨色与朱红
  （呼应 `HOLIDAY_RED #8b0000`），辅以浅灰蓝网格。
- 字体：标题用衬线（衬线 + 中文老宋体更贴合手帐/古籍），正文用无衬线保证可读性。
  项目里有 `京華老宋体v3.0.ttf` 可用于标题/中文强调。
- 动效克制：只在前 4 区（翻页、装订高亮、拼版示意）用轻量动画，其余静态。
- 响应式：桌面（陈列 3–5 列）优先；窄屏降为单列堆叠。

## 四、落地建议（下一步）

1. 先做**静态版**（01、03、04 为主），用“双页标注释图”讲装订区分——这是说服力核心。
1. 素材来源：用后端渲染几个真实 PDF（如 A5 横线 + 月历 + 八分周视图的整本样张）转成大图，
   放到静态资源里，比手绘示意图更有说服力。
1. 版式画廊可直接复用 `src-tauri/gen` / 样例生成的 pattern PDF。
1. 交互版（边距滑块、拼版 toggle、走马灯）留到静态版确认后再加，避免前期过度开发。

> 概要：展示页 = “整本成书 → 装订自动区分 → 三拼版 → 16 版式 → LaTeX 技术 → CTA”。
> 前 4 区讲“为什么省事”，中 2 区讲“能做出什么 / 凭什么可信”，最后收回转化。
