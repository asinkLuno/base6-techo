# LaTeX 框架实施记录

## 目标与术语

- 全书实际页序：从 1 开始连续计数，唯一决定装订侧；跨 section 不重置，隐藏显示页码也照常计数。
- 节内索引：从 0 开始，仅供页心模板决定内容。
- 显示页码：只有参与编号的 section 消耗编号；与实际页序独立。
- 页心：扣除页头、页脚、装订侧、外侧留白后的区域。
- 拼版：将阅读顺序重排到印刷纸张，本次框架不负责拼版。
